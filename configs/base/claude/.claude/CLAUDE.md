# System Context

## Environment
- **Dotfiles**: `~/.dotfiles` → github.com/thebrokencube/files-with-a-dot
- `~/.dotfiles/symlink_map.txt` — What's linked where
- `~/.dotfiles/managed_map.txt` — Merged files (base + private → destination)

## Do NOT
- **Edit generated files.** `~/.claude/settings.json`, `~/.claude/plugins/*.json` are generated by `dot sync` from `~/.dotfiles`. Check `symlink_map.txt` and `managed_map.txt` first. Edit the source in dotfiles, commit, then `dot sync`.
- **Use absolute paths for CLI tools.** `folio`, `dot` are on PATH via `~/.local/bin/`.

## Git
- Do NOT add Co-Authored-By or other trailers to commits
- Use conventional commits: `type(scope): description` (see commit skill)
- One logical change per commit — don't mix refactoring with features. Refactors before features; deps in own commits.
- Stacked branches: follow propagation and fixup rules (see stacked-pr skill)
